Response
Triaged by NIST control mapping, prioritized CAT I equivalents. Automated Security Hub → DynamoDB finding ingestion. Delivered updated POA&M with risk-accepted items, milestone adjustments, and AO briefing within 48 hours.
AWS Security Hub POA&M · ConMon SI-2 · RA-5 · CA-7 ATO Maintained
Scenario 03 · STIG Hardening
30+ CAT I STIG Findings at Pre-Assessment
Risk Finding
SCAP scan surfaces 30+ CAT I open findings on Windows Server baseline two weeks before SCA. Default accounts enabled, audit logging misconfigured, unsigned drivers present.
Response
Applied Evaluate-STIG automated remediation scripts, pushed hardened GPO baseline via Group Policy. Re-ran SCAP post-remediation — reduced CAT I findings to 2 accepted-with-justification before SCA window.
DISA STIG · SCAP Evaluate-STIG CM-6 · AU-2 · SI-7 SCA Passed
Scenario 04 · CloudFormation + GRC IaC
New AWS Workload Requires ATO — No Baseline Exists

Engineering team deploying new EC2-based workload on AWS. No security baseline, no CloudTrail, no encryption at rest, no VPC flow logging. NIST 800-53 controls unimplemented and undocumented.
Response
Built CloudFormation template with GRC controls embedded: encrypted EBS, VPC flow logs, IAM least-privilege roles, CloudTrail enabled, Config rules active. SSP Section 13 controls pre-mapped to IaC implementation evidence.
